# Лабораторная работа №1. Матрицы комплексных чисел

## Структура

- `src/lab1/Complex.java` — комплексное число и арифметика над ним
- `src/lab1/Matrix.java` — матрица комплексных чисел и матричные операции
- `src/lab1/MatrixOperations.java` — операции над матрицами
- `src/lab1/ConsoleInterface.java` — консольный интерфейс
- `src/lab1/Main.java` — вход в программу


Компиляция:
    javac -d bin src/lab1/*.java
Запуск:
    java -cp bin lab1.Main

## В программе реализованы

1. Создание матрицы комплексных чисел любого размера
2. Сложение, умножение, деление матриц
3. Транспонирование матрицы
4. Вычисление определителя методом Гаусса
5. Хранение последнего результата для дальнейшей работы с ним
